# MRFC Functional Core

Rama de estabilización creada sobre `feature/cloud-core-v1` para llevar MRFC al flujo mínimo funcional de producción.

Objetivo inmediato:

1. Configuración PHP/MySQL.
2. Registro e inicio de sesión.
3. Sesión persistente y CSRF.
4. Persistencia central de gastos y comprobantes.
5. Interfaz conectada al backend sin depender únicamente de localStorage.

Esta rama no mezcla versiones anteriores de MRFC; parte del Cloud Core actual.
